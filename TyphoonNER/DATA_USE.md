# Data use and third-party text

This package contains annotated sentence excerpts from third-party news, government, and meteorological sources. Preparing this package does not establish permission to redistribute those underlying texts. No blanket software or Creative Commons license is granted by this package.

The archived release-preparation record identified unresolved text-redistribution permissions. Before making the repository public, the maintainers should resolve and document the applicable redistribution basis and usage terms. Original text rights remain with the respective rights holders; this notice is not itself permission to redistribute or reuse the material.

This candidate includes the complete frozen text for technical inspection. It has not been uploaded to a public repository by the packaging process. Complete source URLs are not supplied, and no missing provenance has been guessed.
